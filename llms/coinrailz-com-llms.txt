## What is Coin Railz?

Coin Railz is agentic commerce infrastructure — pay-per-call APIs built for autonomous AI agents.
Agents pay per call using x402 (HTTP-native USDC micropayments) or card-funded API keys.
No subscriptions. No OAuth. No human in the loop.

## Core Capabilities

- **Canonical service catalog** spanning DeFi, IoT, satellite data, prediction markets, RWA tokenization, and compliance
- **x402 protocol** — 80 canonical services return a live HTTP 402 challenge; agents select its exact `accepts` entry, sign it, and retry with `PAYMENT-SIGNATURE` or `X-PAYMENT`
- **API key access** — card-funded credits, instant provisioning (~60 seconds)
- **USDC Yield Vault** — ERC-4626 on Base, auto-routes across Aave v3, Compound v3, and Morpho Blue
- **A2A payments** — agent-to-agent settlement at /a2a endpoint (A2A protocol 0.3.0)
- **MCP server** — full MCP tool manifest at /mcp

## Pricing

- Service prices are returned by the live HTTP 402 challenge and the canonical catalog
- No fixed protocol minimum or documented withdrawal minimum is claimed
- Full price list: https://coinrailz.com/x402

## Cloudflare Agent Gateway

Coin Railz is also accessible via a native Cloudflare Worker gateway — the preferred entry point for agents built on Cloudflare's Agent SDK or using Cloudflare Wallets.

- **Gateway root:** https://coinrailz-x402-gateway.coinrailz.workers.dev
- **Service catalog:** https://coinrailz-x402-gateway.coinrailz.workers.dev/catalog
- **Payment:** CF Wallet agents pay via the Coinbase CDP facilitator (same as the main platform)
- **Coverage:** Dynamically sourced from the canonical service catalog

## Supported Payment Networks

Base remains available. Arc Mainnet is available through Circle Gateway at `eip155:5042` with USDC `0x3600000000000000000000000000000000000000`; Gateway verifier `0x77777777Dcc4d5A8B6E418Fd04D8997ef11000eE`; facilitator `https://gateway-api.circle.com`. Agents must use the exact `accepts` entry from a live HTTP 402 challenge rather than hardcoding payment details.
